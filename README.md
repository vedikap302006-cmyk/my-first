# 🌐 Personal Portfolio Website

A personal portfolio website created to showcase my skills, education, projects, and interests in the field of Computer Science and Cloud Computing.

## 🚀 Technologies Used

- HTML5
- CSS3
- AWS S3
- GitHub

## ☁️ AWS S3 Static Website Hosting

This portfolio website is hosted as a static website using an **Amazon S3 bucket**.

### Hosting Steps

1. Created an S3 bucket in AWS.
2. Uploaded the HTML and CSS files.
3. Enabled Static Website Hosting.
4. Configured the bucket permissions.
5. Set `index.html` as the default root document.
6. Accessed the portfolio using the S3 website endpoint.

## ✨ Features

- Responsive portfolio design
- About Me section
- Education details
- Skills section
- Projects section
- Contact information
- Cloud-based hosting using AWS S3
